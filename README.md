# SRT-Android App

本仓库用于安装包与后续更新分发。

当前版本 **2.0.0 / code10**，支持 Android 8.0 及以上。

>_声明仅供学习

## 下载与更新

## 新版界面

- 固定入口：首页、地图、识别、记录、我的。
- 首页显示当前位置天气；地图支持病点、田块边界、筛选、回放与巡查路线。
- 统一颜色，采用可分发的黑体、宋体与新罗马兼容字体。
- 调用 Google 官方图标与真实稻穗摄影。

>_保留原有功能模块。模型和阈值未更换。
