# 稻视界 Android

本仓库用于安装包与后续更新分发。当前版本为 **1.2.1**。

## 手机安装和更新

1. 首次安装：下载 [1.2.0完整安装包](https://github.com/julibeian/ricesight-android/releases/download/v1.2.0/ricesight-1.2.0-full.apk)，约60 MB，Android 8.0及以上。
2. 在手机中打开稻视界，进入“设置 → 软件更新 → 手动检查更新”。
3. 下载1.2.1差分（约3.82 MiB），准备完成后点击“继续安装”，按Android提示允许来源并确认更新。

已有1.2.0直接执行后两步。旧1.1.0没有更新入口，需要先完整覆盖安装1.2.0。请保留原应用，不要卸载或清除数据。

[1.2.1发布说明、差分、校验值与对应源码](https://github.com/julibeian/ricesight-android/releases/tag/v1.2.1)

## 当前验证范围

完整工作台包括连续相机/图片/视频识别、前台巡检、防治资料、教学、治理、报告、田块地图、科普、天气和可配置AI。API34模拟器已实际完成从公开1.2.0的应用内差分下载/还原、Android系统覆盖安装至1.2.1，并核对原有观察记录、附件和工作台资料全部hash保持一致。损坏待安装包的恢复、新版模型按需加载和更新清单再次检查均通过。
