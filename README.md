# 稻视界 Android

本仓库用于安装包与后续更新分发。当前版本为 **1.3.0**。

## 手机安装和更新

1. 首次安装：下载 [1.2.0完整安装包](https://github.com/julibeian/ricesight-android/releases/download/v1.2.0/ricesight-1.2.0-full.apk)，约60 MB，Android 8.0及以上。
2. 打开稻视界，进入“设置 → 软件更新 → 手动检查更新”。
3. 下载1.3.0差分（约8.12 MiB），准备完成后点击“继续安装”，按Android提示允许来源并确认覆盖更新。

已有官方1.2.0或1.2.1可直接执行后两步。旧1.1.0没有更新入口，需要先完整覆盖安装1.2.0。请保留原应用，不要卸载或清除数据。

[1.3.0发布说明、差分、校验值与对应源码](https://github.com/julibeian/ricesight-android/releases/tag/v1.3.0)

## 本次新增

- 已审核题随机整场考试、逐题讲评、明确的简答人工自评、持久成绩和JSON/CSV成绩单。
- 错题间隔复习与场次/进度真实分页，异常退出恢复时补齐进度且不重复累计。
- 中文A4 PDF报告，保留筛选和完整证据，最多50页；支持横屏滚动和文件选择期间重建恢复。
- 地图缓存可靠性、旧缓存非实时标识和明确错误阶段。

原有连续相机/图片/视频识别、前台巡检、防治资料、治理、田块地图、科普、天气和可配置AI保留。

## 当前验证范围

Android 12/API31与Android 14/API34模拟器分别实际完成公开1.2.0→1.3.0、1.2.1→1.3.0的应用内差分下载/还原和Android系统覆盖安装。各设备升级前的观察、附件和田块资料全部hash保持一致。升级后的正式包在每个模拟器通过5项教学/表单/横屏/导航、5项PDF测试及1项公开更新检查；签名构建、45项单元测试和release lint通过。

Reno12及其他真机尚未完成本版验收。当前网络的OSM瓦片直连仍中断，已有缓存与坐标层可用；缓存测试不表示服务网络可达。图片人机考核、PDF/Word教材解析及部分作者工作台细分功能继续完善。模型权重未更换，本次不宣称识别准确率提高；未检出不代表健康，药剂资料需核对产品标签。
