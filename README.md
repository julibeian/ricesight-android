# SRT-Android App

本仓库用于安装包与后续更新分发。

当前版本 **2.0.0 / code10**，支持 Android 8.0 及以上。

## 下载与更新

[下载 2.0.0 完整安装包](https://github.com/julibeian/ricesight-android/releases/download/v2.0.0/ricesight-2.0.0-full.apk) · [发布说明、源码与校验](https://github.com/julibeian/ricesight-android/releases/tag/v2.0.0)

首次安装直接打开 APK。已有官方版本可覆盖安装，请保留原应用，不要先卸载或清除数据。

官方 1.2.0、1.2.1、1.3.0、1.4.0 以及本机发放的 2.0.0/code9 预览版均提供直达本版的精确差分。差分按安装包版本、大小和 SHA256 匹配；其他来源或不同字节的 APK 可使用完整安装包。

旧版进入「设置 → 软件更新」，新版进入「我的 → 检查更新」。下载完成后由 Android 确认覆盖安装，无需 USB 调试。2.0.0/code9 预览与本次 code10 显示名称相同，内部版本号更高，仍可正常更新。

## 新版界面

- 固定入口：首页、地图、识别、记录、我的。
- 首页显示当前位置天气；地图支持病点、田块边界、筛选、回放与巡查路线。
- 文字统一纯黑、纯白，采用可分发的黑体、宋体与 Times 兼容字体，构建时检查冗长文案和字色。
- Google 官方图标与真实稻穗摄影；来源和许可可从「我的 → 素材署名」查看。
- 保留连续相机、图片/视频识别、巡检、防治、教学考核、治理、报告和可配置 AI。模型和阈值未更换。

地图与天气需要联网并授权定位；无法访问 GitHub 时可从本页下载完整包安装。未检出目标不代表健康，药剂资料需核对产品标签。

## 验证与源码

单元测试、构建守卫、Release lint、正式签名、10 个原生库的 16KiB 静态检查，以及 API34 模拟器导航、黑白文字、地图、真实天气和田块保存已验证。模拟器位置为测试注入；手机 GPS、相机与持续性能仍待现场验收，静态检查不等于真机运行验收。
