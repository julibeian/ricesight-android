# 稻视界 Android

本仓库用于安装包与后续更新分发。

当前完整版本：**1.2.0（code5）**，约60 MB，Android 8.0及以上。

- [下载完整安装包](https://github.com/julibeian/ricesight-android/releases/download/v1.2.0/ricesight-1.2.0-full.apk)
- [发布说明、校验值和对应源码](https://github.com/julibeian/ricesight-android/releases/tag/v1.2.0)

在手机上打开安装包覆盖安装，保留原应用，不要卸载或清除数据。此前1.1.0没有应用内更新入口，需要先完整覆盖安装此版。

现有工作台包含连续相机/图片/视频识别、前台巡检、防治资料、教学、治理、报告、田块地图、科普、天气和可配置AI。本版加入“设置 → 软件更新 → 手动检查更新”，读取官方签名清单；后续差分按已公开安装包的完整SHA256与大小匹配，还原校验后由Android确认安装。

本次没有宣称真实5→6差分系统安装链、Reno12新版真机验收或作者全部细分功能已完成。天气实际查询已验证；当前模拟器网络上的地图瓦片请求仍未通过，坐标层可用。模型权重未更换，本次不宣称识别准确率提升。未检出不代表健康；药剂资料需核对产品标签。

源码以对应Release中的归档分发。模型及资料来源、依赖许可和未核验边界见各版本SOURCE_NOTICE.md。源码包不包含私人照片、数据集、凭据或签名私钥。
