# 稻视界 Android

本仓库用于安装包与后续更新分发。当前版本为 **1.4.0（code8）**，Android 8.0及以上。

## 下载安装

直接下载 [1.4.0完整安装包](https://github.com/julibeian/ricesight-android/releases/download/v1.4.0/ricesight-1.4.0-full.apk)（63,056,628字节，约60.1MiB），按Android提示安装即可，无需先安装旧版本。已有官方旧版可以保留原应用并覆盖安装，请不要卸载或清除数据。

完整包SHA256：

`fbe961ec1857105a79fee8b11bace13dbe8a58814eee409439573d2fb0e1734a`

[发布说明、完整包、差分、校验值及对应源码](https://github.com/julibeian/ricesight-android/releases/tag/v1.4.0)

## 软件内更新

进入“设置 → 软件更新 → 手动检查更新”，按提示下载差分，准备完成后点击“继续安装”，由Android确认覆盖安装；不需要USB调试。

官方1.2.0、1.2.1和1.3.0均提供直达1.4.0的差分，约8.28MiB。实际适用性取决于安装包的精确身份。旧1.1.0没有软件内更新入口，可直接完整覆盖安装1.4.0。本次按用户要求同时提供最新完整安装包，后续仍保留应用内差分更新。

## 本次新增

- 图片人机考核：主动选图、填写来源并人工审核参考类别；先答题，再查看模型结果和讲评，完成整场后才能导出成绩。
- 报告文件管理：对主动选入或成功导出的文件建立本地索引，可搜索、修改备注、打开和重新关联；删除索引不会删除用户文件。
- 病害科普：程序化植株结构展示，支持全屏、线框、手势与复位，按需查询近14天本机记录数。

原有连续相机、图片/视频识别、前台巡检、防治资料、随机考试与间隔复习、治理登记、中文PDF及CSV/JSON/HTML报告、田块地图、天气和可配置AI保留。图片考核不自动训练模型或写入原识别历史；文件索引不解析PDF/Word正文；植株示意和记录数不代表田间实物或病情严重度。
